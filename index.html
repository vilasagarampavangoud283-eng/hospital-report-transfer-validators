How the System Works

  1. Select a hospital report, PDF, image or other file on the Sender Side.
  2. Generate the Reference CRC-32.
  3. Transfer the file to the Receiver.
  4. Enable Error Simulation if you want to demonstrate transmission corruption.
  5. Receiver calculates the Current CRC-32.
  6. Click Verify Report.
  7. If both CRC values match, the report is VALID.
  8. If CRC values are different, ERROR DETECTED is displayed.
  9. A successfully verified file can be saved using Save File.
